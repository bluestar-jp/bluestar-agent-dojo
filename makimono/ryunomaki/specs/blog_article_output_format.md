# ブログ記事出力形式仕様

- Purpose: 技術ブログ記事の出力形式とテンプレート定義
- Scope: Zenn frontmatter、Markdown構造、記事タイプ別テンプレート

## 1. 基本出力形式

### ファイル構造

```text
articles/
  <slug>.md          # 記事本体（Zenn形式）
```

### Zenn Frontmatter仕様

```yaml
---
title: "記事タイトル（60文字以内推奨）"
emoji: "📝"         # 記事を象徴する絵文字（1文字）
type: "tech"         # tech: 技術記事 / idea: アイデア記事
topics: ["react", "typescript", "nextjs"]  # タグ（5つまで、小文字英数字とハイフン）
published: false     # true: 公開 / false: 下書き
publication_name: "" # Publicationに投稿する場合のみ指定
---
```

#### フィールド詳細

- **title**: 必須。記事のタイトル。60文字以内推奨。
- **emoji**: 必須。記事一覧で表示される絵文字。1文字のみ。
- **type**: 必須。`tech`（技術記事）または`idea`（アイデア記事）。
- **topics**: 必須。記事に関連するタグ。最大5つ。小文字英数字とハイフン（`-`）のみ使用可能。
- **published**: 必須。`true`で公開、`false`で下書き。初稿は`false`推奨。
- **publication_name**: オプション。Publicationに投稿する場合のみ指定。

### Markdown本文構造

```markdown
---
<frontmatter>
---

# 記事タイトル（H1は自動生成されるため通常は不要）

## 導入セクション

<導入段落>

## メインセクション1

<本文段落>

### サブセクション（必要に応じて）

<詳細段落>

## メインセクション2

<本文段落>

## まとめ

<まとめ段落>
```

## 2. 記事タイプ別テンプレート

### Template 1: How-to記事

**用途**: 特定のタスクや問題を解決する手順を示す

**構成パターン**:

```markdown
---
title: "<技術名>で<課題>を解決する方法"
emoji: "🔧"
type: "tech"
topics: ["<関連技術1>", "<関連技術2>"]
published: false
---

## はじめに

<課題の明示と記事のゴール>

## 前提条件

- 必要な知識レベル
- 必要な環境・ツール
- バージョン情報

## 手順

### Step 1: <ステップ名>

<具体的な手順>

```<言語>
<コード例>
```text

<説明>

### Step 2: <ステップ名>

<具体的な手順>

### Step 3: <ステップ名>

<具体的な手順>

## トラブルシューティング

### <問題パターン1>

<原因と解決策>

### <問題パターン2>

<原因と解決策>

## まとめ

<達成したこと、次のステップ>

## 参考リンク

- <関連ドキュメント>

```

**適用例**: 「Next.jsでOGP画像を動的生成する方法」「DockerでPostgreSQL環境を構築する手順」

## 3. 段落レベルのJSON構造

記事生成プロセスでは、以下のJSON構造で段落を管理する：

```json
{
  "article": {
    "frontmatter": {
      "title": "記事タイトル",
      "emoji": "📝",
      "type": "tech",
      "topics": ["react", "typescript"],
      "published": false
    },
    "template_type": "how-to",
    "sections": [
      {
        "heading": "はじめに",
        "level": 2,
        "paragraphs": [
          {
            "id": "P1",
            "content": "段落の本文テキスト",
            "type": "text",
            "word_count": 150
          }
        ]
      },
      {
        "heading": "手順",
        "level": 2,
        "paragraphs": [
          {
            "id": "P2",
            "content": "Step 1の説明",
            "type": "text",
            "word_count": 100
          },
          {
            "id": "P3",
            "content": "```typescript\nconst example = 'code';\n```",
            "type": "code",
            "language": "typescript"
          }
        ]
      }
    ]
  }
}
```

## 4. 品質基準

### Frontmatterの検証

- [ ] `title`が60文字以内
- [ ] `emoji`が1文字
- [ ] `type`が`tech`または`idea`
- [ ] `topics`が1-5個、小文字英数字とハイフンのみ
- [ ] `published`がbooleanで初稿は`false`

### 本文の検証

- [ ] 見出し階層が正しい（H2→H3、H2の下にH4が来ない）
- [ ] コードブロックに言語指定がある
- [ ] 各セクションに最低1段落の本文がある
- [ ] テンプレートの必須セクションが全て含まれている

### Zenn仕様準拠

- [ ] 画像パスが相対パスまたはHTTPS URL
- [ ] Zennの埋め込み記法（@[youtube]等）を適切に使用
- [ ] 改行コードがLF（`\n`）
- [ ] ファイル名が`[a-z0-9-]+\.md`パターン

## 5. ファイル名規則

```text
articles/
  <yyyy-mm-dd>-<slug>.md
```

- **日付**: 記事作成日（YYYY-MM-DD形式）
- **slug**: 記事を識別する短い文字列（小文字英数字とハイフン、20-50文字推奨）

**例**: `2024-03-15-nextjs-ogp-generation.md`
