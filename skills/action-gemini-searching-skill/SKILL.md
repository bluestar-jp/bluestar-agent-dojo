# Gemini Web Search Skill

- Purpose: Gemini CLIによるWeb検索で最新情報を取得する
- Scope: 単一アクションとしてのWeb検索実行

## 入力

| パラメータ | 必須 | 説明 |
| ---------- | ---- | ---- |
| query | Yes | 検索クエリ（具体的かつ簡潔に指定する） |

## 実行手順

1. ユーザーの要求から検索クエリを構成する
2. 以下のコマンドを実行する:

   ```bash
   gemini -p "{query}"
   ```

3. 結果をユーザーの質問に関連する形で要約・整理する

## 使用場面

- 最新のライブラリバージョンやドキュメントの確認
- トレーニングデータに含まれない最新情報の取得
- 不明なエラーの解決策の検索
- 最新のAPI仕様や技術情報の調査

## 注意事項

- ClaudeのWebSearchツールではなく、必ずこのスキルを使用すること
- 検索クエリは具体的かつ簡潔に指定する
- 複数の検索が必要な場合は、1つずつ実行する

## エラーハンドリング

- **geminiコマンド未インストール**: エラーを報告し、`npm install -g @anthropic-ai/gemini-cli` 等のインストール手順を案内する
- **ネットワークエラー**: リトライを1回試み、それでも失敗する場合はユーザーに報告する
